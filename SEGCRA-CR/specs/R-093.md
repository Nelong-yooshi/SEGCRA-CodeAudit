# R-093 高頻轉帳異常

## 說明
本規則偵測單一帳戶於單一交易日內之轉帳筆數是否達 20 筆(含)以上,用於捕捉人頭帳戶高頻分散轉出行為,於次日批次通報。

## 資料表定義(釘死 schema;執行驗證以此建表)
```sql
CREATE TABLE transactions(
  account_id INT, tx_time TIMESTAMP, channel VARCHAR,
  tx_type VARCHAR, amount DECIMAL(14,2), currency VARCHAR);
```

## 需求項目
1. **交易範圍**:`tx_type = 'TRANSFER'`(不分通路、不分幣別)
2. **聚合方式**:單日轉帳筆數(每帳戶,`COUNT(*)`)
3. **閾值**:「達 20 筆(含)以上」= `COUNT(*) >= 20`(19 筆**不**通報)
4. **時間窗**:交易日整日,採半開區間(`tx_time >= :start_date AND tx_time < :end_date`);批次窗涵蓋單一交易日
5. **豁免**:無
6. **通報粒度**:每帳戶每交易日至多輸出 1 筆
7. **輸出欄位**:`account_id`、當日轉帳筆數(`tx_count`)

## 補充
- 閾值經核定為「達(含)」= `>=`;數量級為 20,不得任意調低(調低會造成海量誤報)。
