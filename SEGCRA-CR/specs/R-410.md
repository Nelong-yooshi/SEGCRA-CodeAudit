# R-410 零售帳戶多條件異常清單

> 格式依 `examples/sample/RETAIL_M1_spec.md` 的骨架整理(多條件 OR-of-ANDs、
> 「介於」含兩端、排除清單、待補),並補上執行驗證所需的**資料表定義**段。
> 這是最接近真實規則長相的一份:條件成組、組內全成立、組間任一成立即通報。
>
> ⚠️ 合成資料:表名、欄位、代碼、金額門檻皆為虛構,僅供評測使用。

## 基本資料

| 欄位 | 值 |
|---|---|
| 序號 / 程式名稱 | SAMPLE03 / R-410 |
| 資料取用 | txn_log |
| 是否執行加分模組 | 否 |
| 是否執行 EarlyJob | 否 |
| 程式負責人 | 資料工程團隊 |

## 說明

對當日交易依 `op_code` 分類計算出入帳指標,符合篩選條件 1 或條件 2 **任一**者
列入異常清單,於次日批次通報。

## 資料表定義(釘死 schema;執行驗證以此建表)

```sql
CREATE TABLE txn_log(
  account_id INT, tx_time TIMESTAMP, op_code VARCHAR, amount DECIMAL(14,2),
  cash_flag VARCHAR, rev_flag VARCHAR, channel_name VARCHAR);
```

## 排除資料

- **沖銷交易**:`rev_flag = 'Y'` 者不列計。
- **小額入帳**:入帳單筆金額**小於等於 1,000** 者不列計。
- **行銷活動撥入**:`channel_name = 'PROMO'` 不列計。

## op_code 分類

- **入帳 op_code**:`OP01`、`OP02`、`OP03`。
- **自助設備出帳 op_code**:`OP11`、`OP12`。

## 篩選條件(「介於」= **含兩端**;條件 1 或 2 任一成立即列入)

1. **條件 1(下列全部同時成立)**:
   - 1-1 自助設備出帳次數 **介於 2–3 次**(`>= 2 AND <= 3`)
   - 1-2 自助設備出帳總額 **介於 50,000–100,000 元**(`>= 50000 AND <= 100000`)
   - 1-3 入帳總額(已排除小額) **介於 80,000–100,000 元**(`>= 80000 AND <= 100000`)
2. **條件 2(下列全部同時成立)**:
   - 2-1 自助設備出帳次數 **介於 4–10 次**(`>= 4 AND <= 10`)
   - 2-2 自助設備出帳總額 **介於 90,000–150,000 元**(`>= 90000 AND <= 150000`)
   - 2-3 入帳次數(已排除小額) **介於 2–3 次**(`>= 2 AND <= 3`)

## 其他要求

3. **時間窗**:交易日整日,採半開區間
   (`tx_time >= :start_date AND tx_time < :end_date`)
4. **通報粒度**:每帳戶每交易日至多輸出 1 筆
5. **輸出欄位**:`account_id`、自助設備出帳次數(`atm_cnt`)、
   自助設備出帳總額(`atm_amt`)、入帳總額(`in_amt`)、入帳次數(`in_cnt`)

## 待補(核定規格未載明,不從程式碼腦補)

- **兩組條件同時成立時**:規格未載是否需標示命中哪一組,現行僅輸出一筆。
- **無自助設備出帳的帳戶**:規格未載次數為 0 時是否參與條件判斷。
- **金額欄位的幣別/單位**:規格未載是否需限制單一幣別。

## NULL 語意(排除條件的必要說明)

排除條件一律解為「**只排除明確標記者**」:欄位為 NULL 代表「未標記」,
**不等於**被排除的類別,應予列計。

實作上不可直接寫 `col <> 'X'`——SQL 三值邏輯中 `NULL <> 'X'` 回傳 UNKNOWN,
`WHERE` 會把該筆濾掉,造成**靜默漏報**。正確寫法:

```sql
COALESCE(col, '<非該類別的預設值>') <> 'X'
-- 或
(col <> 'X' OR col IS NULL)
```

本規則的資料表定義未對這些欄位加 `NOT NULL`,故此條為必要要求。

## 補充

- 所有「介於」一律解為**含兩端**;邊界案例(恰 2 次、恰 3 次、恰 50,000、
  恰 100,000…)**應**通報。若某條實為「超過(不含)」須在規格明寫。
- 條件組之間是 **OR**,組內各子項是 **AND**——漏掉任一子項都會使命中範圍變寬。
