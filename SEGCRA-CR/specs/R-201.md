# R-201 單日 ATM 現金提領累計異常

## 說明
本規則偵測單一帳戶於單一交易日內,透過 ATM 通路之現金提領累計總額是否達新臺幣 100,000 元(含),於次日凌晨批次執行,通報單交付調查部門。

## 資料表定義(釘死 schema;執行驗證以此建表)
```sql
CREATE TABLE transactions(
  account_id INT, tx_time TIMESTAMP, channel VARCHAR,
  tx_type VARCHAR, amount DECIMAL(14,2), currency VARCHAR);
CREATE TABLE exempt_accounts(account_id INT);
```

## 需求項目
1. **交易範圍**:`tx_type = 'WITHDRAW' AND channel = 'ATM'`
2. **聚合方式**:單日累計金額(每帳戶)
3. **閾值**:新臺幣 100,000 元;「達(含)」= `>= 100000`
4. **時間窗**:交易日整日,採半開區間(`tx_time >= :start_date AND tx_time < :end_date`);批次窗涵蓋單一交易日
5. **批次時點**:次日 02:00 執行,統計前一交易日整日資料
6. **幣別**:`currency = 'TWD'`(外幣提款不計入;前置系統不換算)
7. **豁免**:排除 `exempt_accounts` 名單(內部測試戶、代收戶),以 `NOT EXISTS` 實作
8. **通報粒度**:每帳戶每交易日至多輸出 1 筆累計總額摘要
9. **輸出欄位**:`account_id`、當日累計金額(`total_amount`)

## 補充
- 沖正/退匯已於前置系統統一淨額,規則層無需處理(見團隊恆常規範 bind-reversal-netted)。
- 閾值含等經核定為「達(含)」= `>=`。
