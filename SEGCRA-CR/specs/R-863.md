| 欄位 | 值 |

## 說明

計算單一帳戶當日**轉出**累計金額;超過 40,000 元者列入異常清單。

## 資料表定義(釘死 schema;執行驗證以此建表)

```sql
CREATE TABLE txn_log(
  account_id INT, tx_time DATETIME2, op_code NVARCHAR(10), amount DECIMAL(14,2));
```

## 篩選條件(逐條可對測資判 true/false)

1. **交易範圍**:`op_code IN ('OP21','OP22','OP23')`
2. **聚合方式**:單日轉出累計金額(每帳戶,`SUM(amount)`)
3. **閾值**:累計金額超過 40,000 元(`> 40000`,恰 40,000 不通報)
4. **時間窗**:交易日整日,採半開區間(`tx_time >= @start_date AND tx_time < @end_date`)
5. **通報粒度**:每帳戶每交易日至多輸出 1 筆
6. **輸出欄位**:`account_id`、當日轉出累計金額(`total_amount`)

## 補充

- 閾值經核定為「超過」40,000;邊界案例(恰 40,000)**不**通報。
