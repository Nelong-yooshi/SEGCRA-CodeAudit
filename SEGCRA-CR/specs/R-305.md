# R-305 夜間跨行轉帳大額異常

## 說明
本規則偵測單一帳戶於單一交易日內,夜間時段(00:00 起、06:00 前)之跨行轉帳累計總額是否超過新臺幣 200,000 元(不含),於次日批次通報。

## 資料表定義(釘死 schema;執行驗證以此建表)
```sql
CREATE TABLE transactions(
  account_id INT, tx_time TIMESTAMP, channel VARCHAR,
  tx_type VARCHAR, amount DECIMAL(14,2), currency VARCHAR, is_interbank BOOLEAN);
```

## 需求項目
1. **交易範圍**:`tx_type = 'TRANSFER' AND is_interbank = TRUE`
2. **時段**:夜間 00:00–06:00,**不含 06:00 整點**(`EXTRACT(HOUR FROM tx_time) < 6`)
3. **聚合方式**:單日累計金額(每帳戶)
4. **閾值**:新臺幣 200,000 元;「超過」= 不含 = `> 200000`(恰好 200,000 元**不**通報)
5. **時間窗**:交易日整日,採半開區間(`tx_time >= :start_date AND tx_time < :end_date`);批次窗涵蓋單一交易日
6. **幣別**:`currency = 'TWD'`
7. **豁免**:無(本規則不設豁免名單)
8. **通報粒度**:每帳戶每交易日至多輸出 1 筆
9. **輸出欄位**:`account_id`、夜間累計金額(`total_amount`)

## 補充
- 閾值含等經核定為「超過(不含)」= `>`;邊界案例(恰 200,000)不得通報。
- 沖正/退匯已於前置系統統一淨額,規則層無需處理。
